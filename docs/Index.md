## Cómo usar este índice / How to use this index

- Si es la primera vez que visitas el proyecto, empieza por el [README](../Readme.md) y luego sigue la [hoja de ruta](RoadMap.md).
- Si ya conoces el tema, ve directamente a la sección correspondiente y lee los artículos en orden.
- Si quieres proponer o escribir un artículo nuevo, revisa la [guía de estilo](../guides/StyleGuide.md) y la [convención de nombres](../guides/NamingConvention.md).

- If this is your first time visiting the project, start with the [README](../Readme.md) and then follow the [roadmap](RoadMap.md).
- If you already know the topic, jump directly into the relevant section and read the articles in order.
- If you want to propose or write a new article, review the [style guide](../guides/StyleGuide.md) and the [naming convention](../guides/NamingConvention.md).
